# Reproducing the demonstration

Five minutes, no network call, no cost, no pilot data.

Everything starts from the **frozen** `GROUNDED-S1` corpus, not from a working
directory: a demonstration that starts from a moving state does not replay.

---

## What you need

- The instrument, in a version that produces export schema `/2` — for the
  export and for the chain verification.
- The reference freeze.
- Python 3.12 for `verify.py` — **and nothing else**: no dependency, no network.

---

## 1. Verify the starting point

The freeze, before relying on it:

```sh
cd <freeze>
python verifier_gel.py .
```

Expected: `12 PASS, 0 FAIL, 3 NOT TESTED`.

Then the ledger's chaining, with the instrument that wrote it. Expected: 151
records, head hash
`fc1f2787e6e0e24fd70c9b6d252efe99dc9e2fe297233f289254c47a4c7d43b2`, no anomaly.

---

## 2. Produce the evidence file

Export the campaign `grounded-med-synthetique-v1` from the frozen ledger.

The export **refuses** to produce anything if the chain does not verify, if the
campaign has no record, or if the output file already exists. It then re-reads
the archive it has just written and compares it with what it intended to write.

Expected: 1 run, 30 observations, and an `archive_sha256`.

> The archive's hash **changes at every export**, because the manifest carries
> the export timestamp. The member hashes are stable: those are the ones to
> compare. The 5 November 2026 archive was
> `84ff0decfbc12a71034412a2a8f55f7f89f21dc850b49a4b144ebc2075ea516c`.

---

## 3. Verify the file, without NeoMundi

```sh
python verify.py NEOMUNDI_EVIDENCE_DEMO_V0.1.zip \
  --corpus <freeze>/GROUNDED-S1/entrees/corpus
```

Expected: `19 PASS, 0 FAIL, 2 NOT TESTED`.

The two checks not performed are named with their reason: the JCS chaining (out
of scope for an independent verifier, by choice) and the archive's origin (out
of scope for any local verification).

---

## 4. Show that verification is worth something

A verifier that accepts an intact archive proves nothing until it is shown to
refuse a tampered one.

```sh
python tests/test_falsification.py NEOMUNDI_EVIDENCE_DEMO_V0.1.zip \
  <freeze>/GROUNDED-S1/entrees/corpus
```

Expected: `10/10 alterations detected, 1 declared limitation, 0 problem`.

**This is the most useful moment of the demonstration.** The last line — the
falsification that is *not* detected — is the one to show, not the one to hide:
one observation erased everywhere, counts and checksums rebuilt, produces a
coherent archive. Only the hash kept elsewhere detects it.

---

## 5. Read the report

Open `rapport.md` inside the archive, and stop at four places:

1. **"Valeurs `null`"** — "coût non établi : 30 sur 30". No sum is displayed,
   because there is nothing to sum.
2. **"Mesures"** — the per-signal table. `semantic_instability_score`: 8
   measured, 22 `null`. None of those 22 became a `0`.
3. **"Régime d'exécution"** — the guard. It states that `provider_attested`, in
   this file, attests a replayed recording and not a provider, and that a
   measurement identifier may be a sentinel.
4. **"Limites"** — seven statements, inside the archive and not in a brochure.

> The report is in French: it is generated by the instrument, which this release
> does not modify. An English report is a PLANNED item.

---

## What the demonstration establishes, and what it does not

**Established:** a campaign evidence file is produced, read, and verified
without NeoMundi; verification detects tampering; absences are named and never
filled in.

**Not established:** that the measured signals are correct. That the archive is
authentic — no signature, no opposable timestamp. That a buyer wants to pay for
this.

That last point is not a technical limitation. It is the open question.
